# 装配绑定

模板准备阶段提供绑定，装配阶段只能消费，不自行猜测原型或修改绑定。
`template_sha256` 对应批准的模板文件；正文锚点、段落原型均按直属 body 段落的完整文本唯一定位。
正文锚点和原型会被生成内容替换/移除，其他模板内容保留。原型不可含分节或域；原有书签随首次实例保留，重复实例不复制原有书签；新图表/文献使用独立书签；图片原型须恰含一张内嵌图及唯一识别文本。

```json
{
  "template_sha256": "模板文件 SHA256",
  "body_marker": "{{正文}}",
  "paragraphs": {
    "heading1": "{{一级标题原型}}",
    "heading2": "{{二级标题原型}}",
    "heading3": "{{三级标题原型}}",
    "body": "{{正文原型}}",
    "figure": "{{图片原型}}",
    "figure_caption": "{{图题原型}}",
    "table_caption": "{{表题原型}}",
    "bibliography_heading": "{{参考文献标题原型}}",
    "bibliography": "{{参考文献原型}}"
  },
  "tables": {"3": 0},
  "fields": {"{{论文题目}}": "topic", "{{摘要}}": "abstract", "{{关键词}}": "keywords"}
}
```

`tables` 的键是列数，值是模板直属 body 表格的零基索引。多行表格至少有三行原型：首行为表头，第二行为普通数据行，末行为最后数据行。列宽、单元格和三线表格式来自原型；不同列数需不同原型。段落原型只需提供实际会用到的类型，正文及所需标题层级必需。
图片复用模板显示尺寸，编码时按模板长宽比生成，避免失真。新增媒体及关系不会更改已有媒体或关系。
元信息只允许 topic/abstract/keywords；可跨 run 替换，保留原字体和属性。摘要/关键词绑定必需。
输出只允许写入该任务 `assembly/`，校验报告证明受保护部件逐字节一致、分节属性一致与确定性重放一致。
原始模板及批准模板不覆盖；不通过 LibreOffice 回存最终 DOCX，避免格式漂移。PDF 是预览派生物。
